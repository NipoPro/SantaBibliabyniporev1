# Publicar la web de Santa Biblia BYNIPO

Este paquete contiene el sitio web estático ya preparado: `index.html`, recursos `assets/`, icono, manifiesto y política de privacidad.

## Probar en Netlify

1. Extrae el ZIP en tu computadora.
2. Entra en tu cuenta de Netlify y abre la opción **Add new site / Deploy manually** (el nombre puede variar).
3. Arrastra la carpeta extraída que contiene directamente `index.html` y la carpeta `assets/`. No subas solamente el HTML.
4. Abre la dirección HTTPS que Netlify asigne. Prueba la navegación, carga de Génesis 1, lectura de un versículo y lectura consecutiva de un capítulo.

La web necesita Internet para obtener capítulos completos desde sus proveedores de texto. Si un proveedor no responde, la aplicación debe informar que el capítulo no está disponible; no debe inventar versículos.

**Antes de compartir públicamente:** confirma los permisos de uso electrónico de la traducción Reina-Valera 1960 con el titular de derechos. La política de permisos de American Bible Society indica que la integración de RVR60 en una aplicación requiere permiso escrito: https://www.americanbible.org/rights-and-permissions/
